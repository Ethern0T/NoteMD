# Uma nota, bem apresentada

O NoteMD combina a simplicidade do **Markdown** com uma leitura cuidada.
Este parágrafo continua na mesma linha visual, com *itálico*, **negrito com _ênfase_**,
~~texto revisto~~ e `código inline`.

## Ideias com estrutura

- Uma página clara, sem distrações.
- Listas que respeitam a hierarquia:
  - Um detalhe importante.
  - Uma ligação à [documentação de Markdown](https://commonmark.org/help/).
- [x] Organizar o conteúdo.
- [ ] Partilhar a versão final em PDF.

1. Escrever e rever.
2. Exportar a nota.
3. Partilhar um documento legível.

> Uma boa nota deve ser fácil de escrever e agradável de ler.
> A formatação deve ajudar a compreender o conteúdo.

## Um pequeno exemplo

```python
def apresentar(nome: str) -> str:
    # O código mantém a indentação e os caracteres portugueses.
    mensagem = f"Olá, {nome}!"
    return mensagem

print(apresentar("João"))
```

## Comparar sem perder clareza

| Elemento | Apresentação | Estado |
| :--- | :--- | :---: |
| Títulos | Hierarquia e espaçamento | Pronto |
| Texto | Acentos, **ênfase** e ligações | Pronto |
| Tabelas | Colunas alinhadas e cabeçalho | Pronto |
| Código | Fonte monoespaçada e fundo discreto | Pronto |

---

O PDF mantém uma página clara independentemente do tema usado no editor.
As ligações podem ser abertas e o texto pode ser selecionado e pesquisado.
